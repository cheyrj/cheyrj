# Cheyenne Carvalho

I'm a Principal Technical Consultant at FLLR Consulting, a OneTrust partner, based in Rio de Janeiro, Brazil. I implement consent and privacy technology for enterprise websites, mobile apps, and connected TV, plus API integrations with marketing and data systems.

Most of my work lives in client repositories. These public repos are tools I build on my own.

- [**whatsapp-call-transcriber**](https://github.com/cheyrj/whatsapp-call-transcriber): a Swift command-line tool that records WhatsApp desktop calls as two tracks (process tap and mic) and transcribes them locally with macOS 26 SpeechAnalyzer. Nothing leaves the Mac.
- [**launch-audit**](https://github.com/cheyrj/launch-audit): a Node 18+ script with zero dependencies that extracts and audits a full Adobe Launch (AEP Tags) property from its published library. Each OneTrust consent check cites the supporting OneTrust knowledge base article.
